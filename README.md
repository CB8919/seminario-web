# AnimeWeb

AnimeWeb es una aplicación web desarrollada con Django como proyecto para la materia **Seminario Web**, correspondiente a la Tecnicatura Superior en Análisis de Sistemas.

La aplicación permite explorar información sobre anime mediante la integración con la API de AniList y gestionar una lista personal de favoritos.

## Funcionalidades

- Consulta de anime mediante la API de AniList.
- Navegación y paginación de resultados.
- Visualización de información de anime.
- Registro e inicio de sesión de usuarios.
- Gestión de anime favoritos.
- Interfaz web desarrollada con HTML y CSS.

## Tecnologías utilizadas

- **Python**
- **Django**
- **HTML5**
- **CSS3**
- **JavaScript**
- **GraphQL**
- **AniList API**
- **Supabase**

## Instalación y ejecución

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/CB8919/seminario-web.git
   ```

2. Ingresar al directorio del proyecto:

   ```bash
   cd seminario-web
   ```

3. Crear y activar un entorno virtual.

4. Instalar las dependencias:

   ```bash
   pip install -r requirements.txt
   ```

5. Configurar las variables de entorno necesarias para la conexión con los servicios utilizados.

6. Ejecutar el servidor de desarrollo:

   ```bash
   python manage.py runserver
   ```
