# Security Policy

## Supported Versions

SeminarioWeb is an academic project currently under development. Security updates are applied to the current development version when necessary.

| Version | Supported |
| ------- | --------- |
| Current development version | Yes |
| Older versions | No |

## Reporting a Vulnerability

If you discover a potential security vulnerability in SeminarioWeb, please report it privately to the repository owner through GitHub.

Please include a description of the vulnerability and the steps needed to reproduce it, if possible.

Reports will be reviewed as time permits. This project is maintained for educational purposes, so response times and security updates are not guaranteed.

Please avoid publishing details of an unpatched vulnerability publicly.
